Funcionalidades

O que o script faz

Consulta por período

Filtre ofertas por data inicial e final. Sem informar nada, o padrão são os últimos 30 dias.

Consulta por ID

Abra os dados completos de uma oferta específica a partir do ID exibido na listagem.

Tabela no terminal

Resultados formatados diretamente no terminal, usando tabelas legíveis geradas com Rich.

Exportação para Excel

Salve os resultados encontrados em uma planilha .xlsx pronta para análise.

Estatísticas

Geração de estatísticas sobre as ofertas encontradas em cada consulta.

Link direto para a CVM

Cada oferta encontrada aponta diretamente para a página correspondente no portal da CVM.

Como usar

Da instalação ao primeiro relatório

Clone o repositório

git clone https://github.com/trajano-sh/cvm_ofertas_cli
cd cvm-ofertas-cli

Crie e ative um ambiente virtual

python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows

Instale as dependências

pip install -r requirements.txt

Execute a aplicação

O menu principal oferece três opções: filtrar por período, abrir oferta por ID e pesquisa detalhada por planilha da CVM (valores do último dia útil).

python main.py
